# TOEIC 750 ใน 30 วัน

เว็บแอปติว TOEIC ภาษาไทยทั้งหมด สำหรับคนที่เริ่มจากศูนย์ เป้าหมาย 750+ ใน 30 วัน
เปิดได้ทั้งคอมและมือถือ ติดตั้งเป็นแอปและใช้ออฟไลน์ได้ ข้อมูลทั้งหมดเก็บในเครื่องผู้ใช้เอง

## เปิดใช้งาน

| วิธี | คำสั่ง / ลิงก์ |
|---|---|
| เปิดบนคอมเครื่องนี้ | `npm run build && npm run serve` แล้วเปิด http://localhost:8080 |
| เปิดบนมือถือ (Wi-Fi เดียวกัน) | คำสั่งเดียวกัน แล้วใช้ที่อยู่ IP ที่ขึ้นในเทอร์มินัล |
| เว็บออนไลน์ | https://mindanao0.github.io/toeic-750/ |
| ไฟล์เดียวจบ | `dist/single/index.html` — เปิดจากไฟล์ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ |

ติดตั้งเป็นแอปบนมือถือ: เปิดเว็บออนไลน์ → เมนูเบราว์เซอร์ → "เพิ่มลงในหน้าจอหลัก"

## สิ่งที่มีในแอป

- **ข้อสอบจัดระดับ 45 ข้อ** — วัดว่าตอนนี้อยู่ประมาณกี่คะแนน ก่อนเริ่มแผน
- **แผน 30 วัน** — บอกทุกวันว่าต้องทำอะไร เรียงตามคะแนนที่ได้ต่อชั่วโมงที่ลงแรง
- **บทเรียนภาษาไทย 19 บท** — ตั้งแต่การอ่านออกเสียง จนถึงยุทธวิธีรายส่วนและการคุมเวลา
- **ข้อสอบครบ 7 Part** ตามรูปแบบจริง พร้อมเฉลยละเอียดทุกข้อ:
  คำแปลไทยทั้งข้อ · ทำไมตัวเลือกอื่นผิด · จุดไวยากรณ์ที่วัด · เทคนิคตอบเร็ว · ศัพท์ + คำอ่านไทย + IPA
- **ดริลไล่ 3 ระดับ** ง่าย → กลาง → ระดับข้อสอบจริง
- **สอบเสมือนจริง 5 ชุด** จับเวลา ฟัง 45 นาที + อ่าน 75 นาที เสียงเปิดครั้งเดียวเหมือนสนามจริง
- **แฟลชการ์ดคำศัพท์ 600 คำ** ทวนแบบเว้นระยะ (SRS) คำที่ผิดโผล่บ่อยขึ้นเอง
- **สมุดข้อที่ผิด** เก็บอัตโนมัติ ทวนซ้ำจนถูก พิมพ์เป็น PDF ได้
- **สถิติย้อนหลัง** กราฟคะแนนคาดการณ์ · ความแม่นยำรายส่วน · ความเร็วต่อข้อ · จุดอ่อนรายหัวข้อ
- **สรุปไวยากรณ์** เปิดดูเร็วก่อนสอบ
- **ข้อมูลการสอบจริงในไทย**
- streak วันติดกัน · XP · เหรียญตรา · โหมดมืด/สว่าง · ปรับขนาดตัวอักษร · แจ้งเตือนรายวัน

เสียงในส่วน Listening ใช้เสียงอ่านของเบราว์เซอร์ (Web Speech API) สลับ 4 สำเนียงเหมือนข้อสอบจริง
(อเมริกัน / อังกฤษ / แคนาดา / ออสเตรเลีย) โหมดฝึกฟังซ้ำได้ไม่จำกัดและดูสคริปต์ได้
โหมดสอบเปิดครั้งเดียว

## โครงสร้างโปรเจกต์

```
src/
  index.html          โครงหน้าเว็บ (มีมาร์กให้ build แทรก CSS/JS/ข้อมูล)
  css/styles.css      สไตล์ทั้งหมด ปรับธีมผ่าน CSS variable
  js/
    00-core.js        ยูทิลิตี้, DOM helper, วันที่, สุ่มแบบ seed ได้
    10-store.js       สถานะผู้ใช้ + localStorage + XP/streak/เหรียญตรา
    20-score.js       ตารางแปลงคะแนนดิบเป็นคะแนน TOEIC + คะแนนคาดการณ์
    30-tts.js         เสียงอ่าน 4 สำเนียง
    40-data.js        โหลดคลังเนื้อหา (ฝังในไฟล์ / โหลดทีละไฟล์)
    50-srs.js         อัลกอริทึมทวนคำศัพท์ (ดัดแปลง SM-2)
    60-ui.js          ชิ้นส่วนหน้าจอ: โจทย์ เฉลย กราฟ เสียง
    65-quiz.js        ตัวรันข้อสอบ (โหมดฝึก / โหมดสอบจับเวลา)
    70..82-views-*.js หน้าจอแต่ละหน้า
    85-notify.js      แจ้งเตือนรายวัน
    90-app.js         router + boot
data/
  drills/*.json       ดริลแยกตาม Part และระดับ
  tests/*.json        ข้อสอบจัดระดับ + ชุดสอบเต็ม
  lessons/L*.json     บทเรียนรายวัน
  vocab/*.json        คลังคำศัพท์
  static/*.json       แผน 30 วัน, สรุปไวยากรณ์, ข้อมูลการสอบ
docs/CONTENT-SCHEMA.md  สคีมาของไฟล์เนื้อหาทั้งหมด
tools/
  validate.js         ตรวจเนื้อหาว่าตรงสคีมา คำตอบครบ ไม่ซ้ำ ตำแหน่งคำตอบไม่เบ้
  smoke.js            เปิดทุกหน้าด้วย headless chromium เช็คว่าไม่มี error
  flow.js             ทดสอบใช้งานจริงตั้งแต่ทำข้อสอบจนบันทึกสถิติ
  serve.js            เซิร์ฟเวอร์ในเครื่องสำหรับเปิดบนมือถือ
```

## คำสั่ง

```bash
npm run build      # สร้าง dist/web และ dist/single
npm run validate   # ตรวจไฟล์เนื้อหาทั้งหมด
npm run serve      # เปิดเซิร์ฟเวอร์ที่พอร์ต 8080
node tools/smoke.js  # ทดสอบทุกหน้าจอ (ต้องรัน serve ค้างไว้)
node tools/flow.js   # ทดสอบการใช้งานจริง (ต้องรัน serve ค้างไว้)
npm run deploy     # build + ทดสอบ + push ขึ้น GitHub Pages
```

ไม่มี dependency ภายนอกเลย ใช้แค่ Node.js ที่ติดตั้งอยู่แล้ว

## การเพิ่มเนื้อหา

เพิ่มไฟล์ JSON ลงใน `data/<kind>/` ตามสคีมาใน `docs/CONTENT-SCHEMA.md`
แล้วรัน `npm run validate && npm run build` — build จะสแกนโฟลเดอร์เองไม่ต้องแก้โค้ด

## ข้อมูลของผู้ใช้

เก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่มีการส่งออกไปที่ใด ไม่มีบัญชีผู้ใช้
ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะหาย — ใช้ปุ่มสำรอง/กู้คืนในหน้าตั้งค่า

## หมายเหตุลิขสิทธิ์

ข้อสอบทุกข้อในโปรเจกต์นี้เขียนขึ้นใหม่ทั้งหมด โดยเลียนแบบเฉพาะ *รูปแบบ* และ *ระดับความยาก*
ของข้อสอบจริง ไม่ได้คัดลอกข้อสอบของ ETS
TOEIC เป็นเครื่องหมายการค้าจดทะเบียนของ ETS ซึ่งไม่มีส่วนเกี่ยวข้องหรือรับรองโปรเจกต์นี้

คะแนนที่แอปแสดงเป็นการ **ประมาณการ** จากตารางแปลงที่อิงช่วงคะแนนที่ ETS เผยแพร่
คลาดเคลื่อนได้ราว ±25 คะแนน ไม่ใช่คะแนนสอบจริง
